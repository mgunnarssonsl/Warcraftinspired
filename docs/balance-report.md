# Ironvale balance report

60 computer-vs-computer matches (normal and hard, the same difficulty on both sides), random maps, factions, styles and seats. 55 were decided; median length 16:30, the middle half between 14:36 and 18:09.

Generated by `npm run analytics` (scripts/analytics.ts). Computer players are a stand-in for people: these numbers show how the rules play out under consistent decision-making, not how a person will fare.
