Controls

  • Left-click select · drag box-select · Shift add/remove
  • Double-click a unit: select all of that type on screen
  • Right-click ground: move · mine/tree: gather · Keep: return cargo
  • M move · S stop · G gather · R return cargo
  • . next idle worker · Space jump to last alert / selection
  • Ctrl+1–9 set group · 1–9 recall (twice to center)
  • Arrows, screen edges or middle-drag to scroll · wheel zoom
  • P pause · ` debug overlay · F1 this panel

Goal for now: put your five Laborers to work. Gold comes from mines (two miners fit inside at once); wood from trees. Resources count only when delivered to your Keep.
